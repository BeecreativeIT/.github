# Beecreative

Siamo una software house di Milano. Costruiamo software su misura per aziende
che hanno processi propri e non vogliono adattarli a un prodotto standard.

**[Merge](https://merge.beecreative.it/)** è il nostro branch di sviluppo: il
nome con cui escono i progetti di integrazione, le web app e le piattaforme B2B.

La maggior parte del codice che scriviamo sta in repository privati dei clienti,
quindi questa organizzazione dice poco di quello che facciamo. I link qui sotto
dicono di più.

## Cosa facciamo

- **[Integrazione sistemi](https://merge.beecreative.it/middleware/)** — far parlare
  gestionale, e-commerce, logistica e portali senza riscrivere quello che già c'è
- **[Web app a supporto del gestionale](https://merge.beecreative.it/web-app/)** —
  inserimento ordini, griglia taglie e colori, listini per cliente, portali
- **[Dati e data warehouse](https://merge.beecreative.it/dati/)** — consolidare
  sorgenti diverse in un modello leggibile, con query e report che reggono
- **[Agenti AI e automazione](https://merge.beecreative.it/ai/)** — dove serve
  davvero, non ovunque
- **[Infrastruttura cloud](https://merge.beecreative.it/cloud/)** — deploy,
  ambienti, continuità
- **[Consulenza tecnica](https://merge.beecreative.it/consulenza/)** — quando la
  domanda è "conviene farlo?" prima di "come lo facciamo?"

Il settore che conosciamo meglio è il
**[fashion B2B wholesale](https://merge.beecreative.it/fashion-b2b/)**: campagne
vendita, riassortimenti, cataloghi, disponibilità.

## Stack

PHP / Yii2 e Vue per le piattaforme, MySQL e Redis per i dati, Docker per gli
ambienti, Astro per i siti statici. Azure e AWS a seconda del cliente.

Sviluppo assistito dall'AI, scelte di architettura umane — motivate e
documentate.
